# City Eyes 3.1 — Satbayev University

Open `index.html` using VS Code Live Server, or run `START-WINDOWS.bat` if Python is installed.

Five curated destinations are hardcoded in `script.js`: Biosfera (Satpayev 27), ANC (Koktem-1 16), Pharmacy (Koktem-1 20), Satbayev Student Polyclinic (Satpayev 22B), and Satbayev Medical Center (main academic building, room 204). Default starting point: Satbayev University (Satpayev 22).

No places database or Overpass requests. Map tiles (OpenStreetMap), routing (routing.openstreetmap.de), and speech recognition may require internet and browser permissions. Routes are not verified accessible or safe; coordinates represent buildings, not entrances. The "nearest" choice uses straight-line distance; the displayed route (when available) is a walking route computed by a third-party service.

Try `Build a route to the nearest pharmacy`, `Find pharmacies`, `Build a route to the nearest clinic`. To avoid location permissions, keep `Satbayev University (demo start)` selected.

Data references: Yandex Maps (Satpayev 22, Satpayev 27), pharmacy directories for Koktem-1 16 and 20, and Satbayev University freshman guide for the clinic and medical center. Check opening hours and accessibility before real-world use.
